## Prototype and test scope

The current full-concept prototype uses a **Quest 3S with tracked controllers**. Its workflow retains the floating photo wall, separate Text and Sticker spheres, direct manipulation and a spatial trash bin. The test covers choosing and inspecting a photo, creating and placing text and a sticker, moving, rotating and resizing content, deleting an unwanted item, then reviewing and confirming simulated publication.

Changes informed by IP1 include clearer contextual instructions and tool labels, sticker previews, red deletion feedback, clearer return controls, and a review/confirmation step for publishing. The study examines whether users can complete the workflow independently after a standard controller briefing.

Barehand tracking, MR passthrough, video editing and real Instagram uploading are outside this test. The original concept remains available below as design history; it is not a claim that all initial features are implemented in IP2a.
