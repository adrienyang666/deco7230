# Spatial Stories — Codex 项目约定

首次接手先读 `CODEX_HANDOFF.md`；迁移操作见 `CODEX_START_HERE.md`。这些文件是项目交接摘要，不是全部聊天记录。当前用户的新指令优先。

- 用简洁中文沟通；用户是交互设计学生，解释操作时给明确的菜单和路径。
- 优先在 Unity 当前打开的同一个工程目录中修改。先确认目录、实际 Unity 版本、Git 状态和现有改动，不要覆盖用户本地工作。能原地修复时不要反复交付整包让用户重新导入。
- 保留“悬浮照片墙 + T／S 球 + 垃圾桶 + 发布”的设计；当前重点是照片主体拼贴与 2026-10-22 的正式测试准备。
- 以实际工程为准：本包是 Unity 6000.3.20f1、Built-in 渲染管线。不要根据早期聊天中提到的 URP 擅自转换管线或升级 XR 包。
- 保留 Unity `.meta` 和 GUID。不要运行旧的 Full Concept 场景生成菜单来覆盖 IP2b 场景。
- 单文件启动补丁须保持自包含；曾因只替换主文件、遗漏新 partial 文件出现 CS0103。`ImmersiveStory.SimulatorStartup.cs` 当前只是兼容占位。
- 区分源码检查、Unity 编译、用户报告的电脑测试与 Quest 真机测试。没有实际执行，不得标记为通过；不得编造参与者或观察结果。
- 能编辑本地文件不等于已连接 Unity Editor。连接编辑器后，先只读确认项目路径、场景和 Console，再执行修改。
- 每次完成实质修改后，简短更新 `CODEX_HANDOFF.md` 中的当前状态、验证证据与下一步，供下一个会话接手。
