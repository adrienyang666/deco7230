# DECO7230 Week 03

Unity 6.3 LTS / Universal 3D (URP)

Activities 1-4 are implemented through the included C# scripts. The project also includes an Editor scene builder that creates the complete scenes with references wired automatically.

Open in Unity 6.3 LTS, then use **Tools > DECO7230 > Build Week 3 Scenes**.

Generated scenes:
- Assets/Scenes/Week3_Activity1.unity
- Assets/Scenes/VectorProducts.unity

Activity 5 (Meta Quest) requires Unity's VR Template and the course OpenXR setup guide; it is kept separate from Activities 1-4.

## Spatial Stories — IP1 Prototype

A complete horizontal prototype for the Spatial Stories / Instagram Story MR concept has been added under `Assets/SpatialStories`.

When this project is opened, Unity automatically builds:

- `Assets/SpatialStories/Scenes/SpatialStories_IP1.unity`

You can also rebuild it manually from:

- `Tools > Spatial Stories > Build or Rebuild IP1 Prototype`

See `Assets/SpatialStories/README_SPATIAL_STORIES.md` for controls, features, and testing notes.
