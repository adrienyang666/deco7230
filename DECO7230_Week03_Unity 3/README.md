# DECO7230 — Spatial Stories IP1

Unity 6.3 LTS project containing the Week 03 learning activities plus the **Spatial Stories** Interactive Prototype 1.

The Spatial Stories prototype is located under:

`Assets/SpatialStories/`

On first open, Unity automatically generates and opens:

`Assets/SpatialStories/Scenes/SpatialStories_IP1.unity`

If needed, rebuild it from:

`Tools > Spatial Stories > Build or Rebuild IP1 Prototype`

See `Assets/SpatialStories/README_SPATIAL_STORIES.md` for prototype controls and testing notes.
